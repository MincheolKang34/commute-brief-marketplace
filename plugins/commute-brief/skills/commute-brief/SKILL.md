# 출근길 날씨·미세먼지 브리핑

## 0. 준비 확인

- 이 플러그인의 **open-meteo MCP 서버**가 켜져 있어야 한다. `geocode`, `get_forecast`, `get_air_quality` 도구가 안 보이면
  `/mcp` 에서 서버 상태를 확인하라고 안내하고 멈춘다.
- 카카오톡 전송은 사용자가 **명시적으로 요청했을 때만** 한다. 이 플러그인은 카카오톡 도구를 포함하지 않으며,
  claude.ai 에 연결한 PlayMCP 커넥터의 `KakaotalkChat-MemoChat` 이 있을 때만 쓴다.

## 1. 도시 정하기

1. 사용자가 도시를 말했으면 그것을 쓴다. 말하지 않았으면 환경 변수 `COMMUTE_BRIEF_CITY` 값을, 그것도 없으면 `서울` 을 쓴다.
2. `geocode` 로 좌표를 찾는다. 결과는 인구순이므로 첫 번째를 쓴다.
   - 결과가 비어 있으면 추측하지 말고 도시 이름을 다시 물어본다.
   - 같은 이름 후보가 여럿이고 첫 번째가 사용자 의도와 다를 수 있으면(예: 구·동 단위 지명) 후보를 보여 주고 고르게 한다.

## 2. 조회

- `get_forecast` (위도, 경도) 와 `get_air_quality` (위도, 경도) 를 호출한다. 서로 독립이므로 한 번에 같이 호출한다.
- 숫자는 **도구가 돌려준 값만** 쓴다. 기억이나 추정으로 채우지 않는다. 도구가 실패하면 실패한 항목은 `확인 못 함` 으로 적는다.

## 3. 출력 형식

터미널에 아래 형식으로 5줄 이내로 보여 준다.

```
[도시] [현재 시각] 기준
날씨: [상태] [현재 기온]°C (체감 [체감]°C) · 최고 [최고]° / 최저 [최저]°
강수확률: [값]%
미세먼지: PM2.5 [값](등급) · PM10 [값](등급)
한 줄 팁: [우산/마스크/겉옷 중 필요한 것만]
```

규칙:

- 미세먼지 등급은 도구가 돌려준 `pm2_5_grade`, `pm10_grade` 를 그대로 쓴다.
- 대기질은 **모델(CAMS) 추정값** 이라 한국 측정소 실측과 다를 수 있다고 한 번 밝힌다.
- 마지막 줄에 출처를 `Weather data by Open-Meteo.com` 으로 적는다.

## 4. 선택: 옷차림 조언

사용자가 옷차림·우산·마스크 조언을 원하면 `outfit-advisor` 에이전트에 2단계에서 얻은 조회 결과를 그대로 넘겨 조언을 받아 덧붙인다.

## 5. 선택: 카카오톡 나챗방 전송

사용자가 보내 달라고 했을 때만 한다.

1. 보낼 내용을 200자 이내로 줄여 먼저 보여 주고, 보내도 되는지 확인받는다.
2. 확인받은 뒤 `KakaotalkChat-MemoChat` 으로 보낸다. 도구가 없으면 없다고 알리고 보내지 않는다.
3. 메시지 첫 줄은 `[출근길 브리핑] [도시] [기준 시각] 기준` 으로 시작한다.
